## 🚀 Sobre o projeto

O **Dr Reparos IA** nasceu da união entre minha experiência prática com manutenção residencial e minha experiência e estudos na área de tecnologia.

A proposta é criar uma plataforma capaz de auxiliar pessoas sem conhecimento técnico a identificar problemas residenciais, entender possíveis causas e receber orientações para realizar reparos com mais segurança.

O projeto está em desenvolvimento e sua arquitetura continuará evoluindo com novas funcionalidades e maior integração com **Inteligência Artificial**.

---

## 📱 Funcionalidades atuais

- 🔍 Diagnóstico guiado de problemas residenciais
- 🧠 Identificação de sintomas e possíveis causas
- ⚠️ Orientações de segurança
- 🛠️ Lista de ferramentas necessárias
- 🔩 Indicação dos materiais necessários
- 📋 Instruções passo a passo
- 🛒 Integração com Mercado Livre para materiais recomendados
- 📹 Opção de videochamada com especialista
- 🏠 Solicitação de atendimento presencial
- 📱 Aplicativo Android funcional
